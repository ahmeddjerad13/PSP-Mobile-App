# PSP - Pedagogical Monitoring Platform

A graduation project developed for University of Biskra students.

PSP is a mobile application designed to help students manage their academic life through timetables, absence tracking, and productivity tools. The project was developed by a team of students as part of the Bachelor's Degree final project.

> Note: This repository is intended to showcase the project and my contribution. The complete source code is not publicly available.

---

## Features

- Weekly Timetable
- Absence Tracking
- Study Hub
- Smart Notifications
- Multilingual Support (Arabic, English, French)
- Dark & Light Mode

---

## Tech Stack

- Flutter
- Dart
- Riverpod
- GoRouter
- Dio
- SQLite
- FastAPI
- MySQL
